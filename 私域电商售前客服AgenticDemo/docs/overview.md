# 私域售前 Demo 总览

## 目标

这套 Demo 不是单纯的聊天页面，而是一套可以演示完整售前闭环的 Agentic 系统：

- 秒级首响承接
- 版本、正品、价格、履约四大主路径问答
- 敏感问题合规拦截
- 点名人工与付款承接工单
- 运营侧试点指标与文档中心

## 关键设计原则

1. 价格只走规则表
2. 正品凭据只走知识库
3. 敏感功效只走白名单
4. 禁忌人群不推进成交
5. 收到付款截图不等于收款成功
6. 知识库无命中时不允许硬答

## 核心场景

| 场景 | 说明 |
| --- | --- |
| 首响承接 | 解决客户进线冷场和流失问题 |
| 版本对比 | 回答日版、孟版、珠峰差异 |
| 正品验真 | 输出扫码/官网/三码合一路径 |
| 确定性算价 | 严格按 SKU 与促销规则表报价 |
| 履约承接 | 回答支付、发货、运费、付款截图 |
| 风险拦截 | 效果承诺、治疗、禁忌人群等直接收口 |

## 技术落地

- 前端：Next.js App Router + React
- 后端：Next.js API Routes
- 规则引擎：本地 TypeScript 售前引擎
- 状态存储：本地内存 Demo Store
- 文档中心：`docs/` 下 Markdown 文档自动注册
- 测试：31 条自动化回归 + 结果报告输出
