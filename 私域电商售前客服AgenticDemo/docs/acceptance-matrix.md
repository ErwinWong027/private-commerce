# 私域售前 Demo 验收矩阵

## 验收目标

- 对话准确率满足规则可解释要求
- 流程流畅度覆盖首响、问答、转人工、付款承接
- 所有高风险场景都能被硬规则拦住

## 31 条测试用例覆盖面

### Golden Path
- 首响欢迎语
- 版本对比与同义词归一
- 正品验真与退款承诺
- 确定性报价与 618 活动算价
- 保存、使用、发货、运费、支付
- 付款截图承接
- 缺货说明

### Hard Case
- 历史人工优惠引用
- 规则库外组合优惠
- 非在售商品
- 日版拆盒诉求
- 不存在规格
- 知识盲区
- 售后外溢场景

### Edge Case
- 效果承诺
- 治疗与替代药物
- 禁忌人群坚持购买
- 点名人工
- 监管凭据诱导
- 付款后承接超时

## 自动化判定维度

| 维度 | 说明 |
| --- | --- |
| 意图识别 | 是否进入正确意图分支 |
| 回复内容 | 是否包含核心口径，不包含违规扩展 |
| 是否转人工 | 高风险场景是否正确触发人工 |
| 行动边界 | 是否命中对应边界决策 |

## 通过标准

1. 所有 31 条用例完成回归
2. 关键场景不出现错价和越权承诺
3. 失败用例可定位到具体规则或回复逻辑
