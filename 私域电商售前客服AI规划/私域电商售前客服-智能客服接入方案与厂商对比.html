方案一句话：我们不是 SaaS，是 FDE（Forward Deployed Engineer，前沿部署工程师）——直接进入客户业务，在客户的企业微信端部署基于 RAG 的 1v1 自动回复售前客服：询价、需求澄清、商品对比、促销算账、发货查询全流程自动应答，人工仅作 RAG 未命中时的兜底转接。交付的不是工具，是「部署即上岗」的业务结果。

1交付模式：FDE，不是 SaaS

SaaS 工具订阅（微伴/尘锋/有赞等）本方案：FDE 定制部署
交付物通用工具账号 + 后台配置界面部署完成、直接自动接待客户的 RAG 客服
知识库建设客户自建（模板导入 + 人工维护）FDE 完成：商品库、合规话术库、促销规则库、问题链
落地效果责任客户自负（效果依赖客户运营能力）FDE 负责调优，按业务结果交付
客户技术投入需运营 + 半技术人员持续配置接近零——适配减肥保健品业态（客服 6-20 人、无专职技术）
为什么 FDE 适合这个业态：减肥保健品私域团队规模小、无技术编制，买了 SaaS 也没人把工具变成「能自动卖货的客服」——FDE 补的正是工具到结果的最后一公里。

2核心技术方案：企微端基于 RAG 的 1v1 自动回复

客户消息进入企微 → RAG 检索定制知识库 → 直接生成并自动发送回复。不采用侧边栏 Copilot、不设人工确认环节；合规内置于知识库（检索到的即是预审核合规语料），而非外挂拦截。

RAG 知识库构成（FDE 建库范围）

商品库SKU、版本/规格、价格、正品溯源凭据（资质文号/授权链路/防伪验证）——标品信任逻辑下「是不是正品/什么版本」是首位高频问题
合规话术库功效表述全部预审核，规避《广告法》功效宣称红线——建库阶段完成合规，检索即合规
促销规则库满减/赠品/组合价规则直接入库，算账问题由 RAG 检索规则直接应答
需求澄清问题链版本/规格/用法适配澄清话术
物流/发货发货时效、快递查询话术，对接订单数据源
FAQ 语料历史会话高频问题沉淀，持续调优

自动化立场（按客户业务口径）

  • 约 10% 售前转化率为正常水位——不对未转化的 90% 做犹豫归因/挽回分析，不为此保留人工环节；转化率作为守护指标进入 OSM 战略地图（维持 ≥10% 不下降，AI 接管期间按周对照监测）
  • 100~1000 元均为中客单价（无「高客单」概念）：售前问题高度标准化（正品版本/价格促销/物流发货三类为主，功效认知已在直播间种草完成），RAG 知识库可充分覆盖
  • 人工角色 = 兜底转接（RAG 未命中 / 客户点名人工），不是在环审核
  • 自动化核心价值：7×24 全天候响应 + 客服人力释放

企微接口能力边界（事实说明，供实施通道确认）

  • 微信客服（kf 账号）API：官方支持消息实时回调 + API 自动发送，客户无需加好友，可挂抖音落地页入口 （企微开发者中心 document/path/94638）
  • 员工号 1v1 私聊：官方 API 不提供实时回调与代发消息接口；实现员工号自动回复需借助非官方客户端自动化方式，实施前需与客户确认账号风险接受度
  • 智能机器人：群内 @ 自动应答（频控 30 条/分钟），1v1 私聊不适用 （document/path/101463）

全流程唯一人工触点：RAG 未命中或客户主动要求时转人工兜底。

三条格局判断

  • SaaS 厂商共同短板：只交付工具——减肥保健品团队没有能力也没有人力把工具变成「能自动卖货的客服」，FDE 补的正是这段最后一公里
  • 通用对话 AI 短板：无品类合规语料与促销规则库，客户自建成本高且有合规风险
  • 本方案护城河：FDE 交付模式 + 减肥保健品类 RAG 资产（合规话术库/促销规则库/问题链）的组合，随交付客户数累积复用

客户挑战预演 Q&A

Q：为什么不直接买微伴/句子互动这类现成产品？
A：它们交付的是工具，知识库和运营仍要客户自己做；FDE 交付的是部署完成、直接自动接待的 RAG 客服，含品类合规话术库——客户团队零技术投入。
Q：100~1000 元中客单价，全自动回复能撑住转化吗？
A：中客单价售前问题高度标准化（正品版本/价格促销/物流发货三类为主——标品信任逻辑，客户不问有没有效，只问是不是正品、什么版本），RAG 知识库可充分覆盖；约 10% 转化率为行业正常水位，自动化的价值在 7×24 响应与人力释放。
Q：合规怎么保证？
A：合规内置于知识库——RAG 只检索预审核的合规语料生成回复，功效表述在建库阶段完成审核，而非事后拦截。
Q：部署要多久？
A：FDE 模式下，知识库构建 + RAG 管道部署 2~4 周可上线首版，随后基于真实会话持续调优。
Q：全自动会不会把 10% 转化率做低？
A：转化率是本项目最重要的守护指标：AI 接管期间按周对照监测，连续两周显著低于基线即触发回滚与知识库复盘；RAG 话术基于会话存档中真实客服对话语料拟合（学习真人成交话术，而非通用模板），目标是「回答合规稳定 + 与真人回答高度拟合 + 不出错不幻觉」——不追求拉高转化上限，但守住不下降。
