▸ 阶段 1: 引流承接与首次响应 — L2 流程详情
加好友与来源识别
#1
👤 角色: 客服/运营 💻 系统: 企业微信 / 渠道活码
输入
抖音直播引流点击, 好友添加请求
输出
已通过好友 + 来源标签
通过好友申请，识别客户来自哪场直播/哪个投放，为后续话术与促销口径打标
🟡 MEDIUM 严重程度
来源打标依赖人工手动备注，高峰漏打标
💥 影响: 无法按直播场次匹配促销口径，算账口径混乱
🔍 根因: 无自动渠道识别与打标，活码分流未系统化
首次响应与欢迎
#2
👤 角色: 客服 💻 系统: 企业微信
输入
客户首条询价消息
输出
首条应答
对客户首条消息作出响应，建立对话
🔴 CRITICAL 严重程度
全天候流量 × 班次制人力：白班首响 1~3 分钟、夜间 >8 小时；夜间咨询占 35%~45% 无人接待
💥 影响: 夜间直播后咨询高峰在等待中冷却流失，首响超时静默离开
🔍 根因: 6-20 人团队不设夜班，人力与全天候流量结构性错位
▸ 阶段 2: 需求澄清与正品答疑 — L2 流程详情
正品溯源与渠道可信答疑
#1
👤 角色: 客服 💻 系统: 企业微信 / 商品资质资料
输入
客户正品/版本疑问
输出
正品凭据与版本说明应答
标品信任逻辑下的首位高频问题——出示资质文号/授权链路/防伪验证，说明孟版/日版等版本区别
🔴 CRITICAL 严重程度
正品凭据、授权链路散落，新客服记不全，答复口径不一
💥 影响: 信任建立慢、口径参差影响转化；资深客服成瓶颈
🔍 根因: 正品溯源知识未结构化沉淀，靠个人记忆与经验
需求与版本澄清问题链
#2
👤 角色: 客服 💻 系统: 企业微信
输入
客户模糊需求
输出
澄清后的需求画像
通过问题链澄清适用版本/规格/用法，收敛到可推荐的 SKU
🟠 HIGH 严重程度
澄清问题链靠客服个人经验，新人易漏问关键条件
💥 影响: 推荐错版本、反复追问，会话轮次拉长（15~30 轮）
🔍 根因: 澄清话术未沉淀为标准问题链知识
功效/安全类长尾答疑（合规敏感）
#3
👤 角色: 客服 💻 系统: 企业微信
输入
低频功效/安全疑问
输出
合规话术应答
功效认知已在直播间完成，此处为低频长尾，须严守《广告法》红线
🔴 CRITICAL 严重程度
合规靠培训+个人自觉，夜间/大促疲劳时段违规话术高发
💥 影响: 触碰功效宣称红线，虚假广告最高罚 100 万~200 万元
🔍 根因: 无预审核合规语料库，语义级违规敏感词挡不住
▸ 阶段 3: 商品版本对比与推荐 — L2 流程详情
商品库检索与版本对比
#1
👤 角色: 客服 💻 系统: 企业微信 / 商品资料表
输入
澄清后的需求画像
输出
版本对比说明
检索 SKU、规格、价格，向客户对比不同版本差异
🟠 HIGH 严重程度
SKU/版本信息散落表格，检索靠翻找与记忆
💥 影响: 响应慢、易报错规格价格
🔍 根因: 商品库未结构化可检索
适配版本推荐
#2
👤 角色: 客服 💻 系统: 企业微信
输入
版本对比说明
输出
推荐方案
结合客户诉求推荐适配版本与购买规格
🟡 MEDIUM 严重程度
推荐质量取决于客服个人水平，参差不齐
💥 影响: 转化受个人能力波动影响
🔍 根因: 推荐逻辑未沉淀为知识规则
▸ 阶段 4: 价格促销算账与下单撮合 — L2 流程详情
促销规则算账
#1
👤 角色: 客服 💻 系统: 企业微信 / 促销规则（人工记忆）
输入
推荐方案, 当场促销规则
输出
精确到手价
按满减/赠品/组合价规则计算客户到手价
🔴 CRITICAL 严重程度
人工心算易错价，促销规则随场变动记不全
💥 影响: 错价引发纠纷/亏损，算账口径全渠道不一致
🔍 根因: 促销规则未入库，无确定性计算工具
下单撮合与促单
#2
👤 角色: 客服 💻 系统: 企业微信 / 下单链接
输入
精确到手价
输出
已下单支付
推送下单链接、临门促单，完成成交（约 10% 转化）
🟡 MEDIUM 严重程度
促单节奏靠资深客服经验，新人成交话术弱
💥 影响: 转化率受客服个人能力波动
🔍 根因: 真实成交话术未沉淀拟合
▸ 阶段 5: 物流发货答疑与移交 — L2 流程详情
发货时效与物流查询
#1
👤 角色: 客服 💻 系统: 企业微信 / 订单物流系统
输入
客户物流疑问
输出
物流状态应答
回答何时发货、快递到哪了等确定性问题
🟡 MEDIUM 严重程度
物流状态需跨系统人工查询，重复问答占用人力
💥 影响: 大量重复咨询挤占售前有效服务时间
🔍 根因: 物流数据未与对话打通，无自动查询
未命中问题兜底移交
#2
👤 角色: 客服/主管 💻 系统: 企业微信
输入
非标/投诉/复杂诉求
输出
转接或升级处理
标准知识未覆盖的问题转由资深客服/主管处理
🔵 LOW 严重程度
无未命中沉淀机制，同类问题反复消耗人力
💥 影响: 知识不积累，长期人效难提升
🔍 根因: 缺少未命中回流补录知识库的闭环
